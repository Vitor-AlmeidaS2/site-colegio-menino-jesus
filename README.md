# Site do Colégio Menino Jesus

Este é o código-fonte do novo site do **Colégio Menino Jesus** (São Luís - MA). Ele foi desenvolvido com [React](https://react.dev/) e [Vite](https://vitejs.dev/), apresentando um design moderno e otimizado.

## Requisitos

- Node.js (versão 16 ou superior)
- NPM ou Yarn

## Como rodar o projeto localmente

1. Abra o terminal na pasta raiz do projeto.
2. Instale as dependências executando:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Abra o seu navegador e acesse o endereço fornecido no terminal (geralmente `http://localhost:5173`).

## Estrutura do Projeto

- `src/components/`: Contém todos os componentes da página (Header, Hero, Features, About, Stats, Footer).
- `src/App.css`: Arquivo de estilização global para os componentes da aplicação.
- `src/index.css`: Arquivo de variáveis de design system, tipografia e reset global.
- `index.html`: Arquivo principal HTML onde o React é montado e os scripts externos (como FontAwesome) são carregados.

## Edição de Conteúdo

Para editar os textos, basta abrir os componentes específicos dentro de `src/components/` e modificar o HTML/React. As imagens são referenciadas por URLs e podem ser substituídas pelas fotos originais do colégio.
